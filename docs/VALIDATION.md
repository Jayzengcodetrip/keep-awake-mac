# 验证范围

本项目区分源代码检查、编译、系统断言行为、界面操作和真实网络效果。

## 已完成的本地检查

2026-09-14，在 Apple silicon、macOS 26.5.2 的构建环境中：

- 公开源码移除开发者专用的应用标识和本机记录。
- universal 编译包含 arm64 / x86_64 两个切片，部署目标为 macOS 13.0。
- 本机构建的临时签名通过严格验证，二进制通过已配置的私人路径扫描。
- 在独立临时安装目录构建、安装和复验成功；未覆盖其他应用。
- 未知同名应用的标识冲突会拒绝安装。
- 使用 Apple Swift 6.3.3 编译并运行断言测试：创建后从系统查询类型及开启级别成功；重复开关和释放检查通过，系统确认本测试的断言已移除。
- 当前发行目录未包含未公证的预编译应用下载包。

系统断言测试方法见 [Tests/README.md](../Tests/README.md)。菜单栏人工验收步骤见 [INSTALL_WITH_AGENT.md](../INSTALL_WITH_AGENT.md)。

## 不能从上述检查推出的结论

- 两个架构都编译成功，不等于每种实体 Mac、每个 macOS 13+ 版本都已人工使用验证。
- 系统断言正常，不等于每个公共 Wi-Fi 的认证会话都不会过期。
- 单次本机成功，不等于每个用户都无需安装编译工具或处理环境差异。
- 本机临时签名成功，不等于已经通过 Apple Developer ID 公证。

如反馈问题，请提供系统版本、芯片架构、最小复现步骤，以及去除个人信息后的错误内容。
